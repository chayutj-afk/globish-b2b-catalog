นำเข้ารายชื่อลูกค้า PEAK

อัปเดตรายชื่อลูกค้า (แท็บ PeakContacts) จากไฟล์ export ของ PEAK ฟอร์มขอ QT ใช้รายชื่อนี้เติมรหัสลูกค้าจากเลขผู้เสียภาษี

วิธี export จาก PEAK
  1. PEAK → ผู้ติดต่อ → พิมพ์รายงาน → เลือก "ผู้ติดต่อ" กลุ่ม "ทั้งหมด" → ดาวน์โหลด
  2. รอแจ้งเตือน "รายงานข้อมูลผู้ติดต่อ พร้อมดาวน์โหลดแล้ว" (กระดิ่ง → ดาวน์โหลด) แล้วเปิดไฟล์ .xlsx
  3. เลือกไฟล์ด้านล่าง ตรวจตัวเลข แล้วกด "นำเข้า" (ข้อมูลเดิมในแท็บจะถูกแทนที่ทั้งหมด)
