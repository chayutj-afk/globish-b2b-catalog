รายการ QT

INV → เงินเข้า (ตามเดือนที่ออก INV)

INV ทุกใบที่ออกในเดือนนั้น ไม่ว่าจะมาจาก QT เดือนไหน แล้วดูว่าเก็บเงินได้แล้วเท่าไหร่ · ยอดก่อน VAT ไม่นับใบที่ยกเลิกหรือถูกแทน

ยังไม่มีข้อมูล QT

ตรวจข้อมูล: รายงานของ PEAK เทียบกับหน้าตามหนี้

ข้อมูลจาก PEAK

ตาราง QT ใช้รายงานใบเสนอราคาและรายงานใบแจ้งหนี้ที่ export จาก PEAK เป็น Excel อัปโหลดใหม่ได้ทุกเมื่อเพื่อให้ตัวเลขเป็นปัจจุบัน ไม่ใช้โควตา PEAK API

วิธี export จาก PEAK
  1. PEAK › รายรับ › ใบเสนอราคา (หรือใบแจ้งหนี้) › พิมพ์รายงาน
  2. เลือกช่วงวันที่ เช่น 01/01 ถึงวันนี้ ประเภท "แสดงข้อมูลพื้นฐาน" แล้วดาวน์โหลดเป็น Excel
  3. อัปโหลดทั้งสองไฟล์ที่นี่ ระบบแยกชนิดรายงานให้เอง เอกสารเลขเดิมจะถูกแทนด้วยข้อมูลใหม่ ส่วนเอกสารช่วงอื่นที่เคยอัปโหลดไว้ยังอยู่
